Google Drive sync

Backs up your encrypted vault to vaultsync-backup.enc and keeps an activity log in vaultsync-activity-log.md in your Google Drive. VaultSync can only see files it created (drive.file permission).

Google sync is not set up for this build. Create an OAuth client of type Chrome Extension for the application ID , put its client ID in .env as GOOGLE_OAUTH_CLIENT_ID and rebuild. See the README for step-by-step instructions.

Security & behaviour

Locks the vault when you haven't used VaultSync for this long.
Fills saved usernames and passwords on matching sites while unlocked.
Adds a row to vaultsync-activity-log.md for every saved or updated login. Privacy note: the log is not encrypted - it lists site names and usernames (never passwords).

Export & import

The export file stays encrypted with your master password.

Importing will replace your current vault. Enter the master password that file was exported with - it becomes your master password.

Danger zone

Deletes the vault, settings and sync state from this browser and disconnects Google. Files in your Google Drive are not deleted.
